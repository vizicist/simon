# Sigil Simon Bop Pad Overlays

These STL files are quadrant overlays for the physical Bop Pad.

- Units: millimeters
- Footprint: 101.6 mm wide by 101.6 mm tall, exactly 4.000 inches
- Shape: quarter-circle quadrant with the right-angle corner at the pad center
- Base thickness: 1.2 mm
- Raised sigil height: 0.9 mm
- Total height: 2.1 mm

Files:

- `sigil_overlay_chaos.stl`
- `sigil_overlay_oracle.stl`
- `sigil_overlay_directive.stl`
- `sigil_overlay_sacred.stl`

Each overlay is generated from the matching SVG in `assets/shapes`. Rotate the printed quadrant as needed for the physical pad zone.
